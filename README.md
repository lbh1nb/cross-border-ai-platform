# 跨境电商 AI 运营中台

> 以飞书为协作入口，用 AI Agent 替代人工重复运营工作，实现从选品到售后全链路智能化。

## 业务用户使用指南（无需任何代码操作）

**业务用户全程只需做两件事**：

### 第一步：请 IT/运维人员完成首次安装（一次性）

IT/运维人员会在你的电脑上双击 `scripts\安装.bat` 完成全部安装，包括：
- 自动创建飞书业务视图（销售总览/预警看板/选品决策）
- 自动配置开机自启（电脑重启后系统自动运行）
- 自动启动后台调度器

安装完成后，**电脑会自动运行所有定时任务，无需任何人工干预**。

### 第二步：打开飞书表格查看数据

系统会按以下时间自动往飞书表格写入数据：

| 时间 | 自动做的事 | 看哪张表 |
|------|-----------|----------|
| 工作日 09:00 | 采集多平台热门商品 | 选品池表 → 切换到"选品决策"视图 |
| 每 30 分钟 | 更新库存预警等级 | 库存预警表 → 切换到"预警看板"视图 |
| 每 30 分钟 | 紧急/预警库存自动推送飞书群 | 飞书告警群 → 查看告警卡片 |
| 每天 18:00 | 生成 AI 日报（第4周上线） | 销售日报表 → 切换到"销售总览"视图 |
| 每 3 天 02:00 | 自动清理旧数据 | 无需操作（保留最近3天数据） |

**操作方式**：打开飞书 → 进入多维表格 → 点击表名旁的视图切换按钮 → 选择对应视图即可。

### 常见问题

**Q：表格数据太多看不过来怎么办？**
A：系统每3天自动清理一次旧数据，只保留最近3天。如需保留更久，请让 IT/运维人员在 `.env` 文件中修改 `DATA_RETENTION_DAYS` 配置项。

**Q：想采集自己关注的品类怎么办？**
A：在飞书"采集配置"表中，停用默认家具配置，添加自己的品类（如"蓝牙耳机"），第二天 9:00 自动按新配置采集。

**Q：电脑重启后系统还会运行吗？**
A：会。安装时已配置开机自启，电脑重启后调度器会自动后台运行。

**Q：如何停止系统？**
A：任务管理器 → 结束 `pythonw.exe` 进程。或双击 `scripts\卸载.bat` 彻底卸载。

## IT/运维人员部署指南

> 以下内容仅供 IT/运维人员首次部署使用，业务用户无需关注。

### 1. 环境要求

- Python 3.11+
- 飞书开放平台开发者账号（已创建自建应用，开通多维表格权限）

### 2. 安装依赖（一次性）

```bash
cd cross-border-ai-platform
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # macOS/Linux
pip install -e ".[dev]"
```

### 3. 配置环境变量（一次性）

```bash
cp .env.example .env
# 编辑 .env，填入飞书应用凭证和表 ID
```

必填配置项：
- `FEISHU_APP_ID` / `FEISHU_APP_SECRET`：飞书应用凭证
- `FEISHU_BITABLE_APP_TOKEN`：多维表格 App Token
- `FEISHU_TABLE_ID_*`：5 张业务表的 Table ID

可选配置项：
- `DATA_RETENTION_DAYS`：数据保留天数（默认 3 天，超过自动清理）
- `FEISHU_WEBHOOK_URL`：飞书 Webhook 机器人地址（用于库存预警自动告警到群）

### 4. 配置飞书 Webhook 机器人（可选，用于告警通知）

如果你希望库存预警自动推送到飞书群，需要创建 Webhook 机器人：

1. 打开飞书 → 创建一个告警通知群
2. 群设置 → 群机器人 → 添加机器人 → 选择"自定义机器人"
3. 机器人名称：`AI 运营告警助手`
4. 安全设置：选择"自定义关键词"，填入 `库存 预警 选品 日报 AI 告警`
5. 复制 Webhook 地址，填入 `.env` 文件的 `FEISHU_WEBHOOK_URL`

验证配置：
```bash
python scripts/test_bot.py
```

看到三条测试消息全部发送成功即表示配置正确。

### 5. 验证飞书连接（一次性）

```bash
python -m src.feishu.auth
```

看到 `✅ tenant_access_token 获取成功` 即表示飞书应用配置正确。

### 6. 运行测试（一次性）

```bash
pytest
```

### 7. 交付给业务用户

将整个项目文件夹交付给业务用户，告知：**双击 `scripts\安装.bat` 即可**。

安装脚本会自动完成：
1. 创建飞书业务视图（销售总览/预警看板/选品决策）
2. 配置开机自启快捷方式
3. 启动后台调度器

业务用户之后只需打开飞书表格查看数据，无需执行任何命令。
库存预警达到紧急或预警等级时，会自动推送到飞书告警群。

## 核心功能

### 1. 选品助手（多平台多品类采集）

**解决什么问题**：不知道该进什么货卖。

**怎么做的**：
- 飞书"采集配置"表定义企业经营品类与采集平台（可自定义，非家具企业也能用）
- 每天 9:00 自动读取启用的配置，循环采集多平台多品类商品
- 默认 5 个家具品类 × 3 个平台（亚马逊/沃尔玛/Wayfair）= 15 条采集任务
- 每条任务采集 5 个商品，共 75 个/天
- 自动清洗过滤（评分/价格/排名）
- 写入飞书选品池表，含商品名/价格/评分/来源平台/利润空间等

**企业自定义**：
- 在飞书"采集配置"表中停用默认配置
- 添加自己的品类（如"蓝牙耳机"/"美妆"等文本字段，无需改代码）
- 选择平台、设置采集数量和优先级

### 2. 库存预警

每 30 分钟检查一次飞书库存预警表，根据可售天数自动更新预警等级（紧急/预警/关注/正常）。

### 3. 数据增量同步（去重）

**解决什么问题**：每次采集都重复写入相同商品，导致表格数据堆积、查看困难。

**怎么做的**：
- 选品池表按 `ASIN + 来源平台` 主键去重
- 库存预警表按 `SKU` 主键去重
- 销售日报表按 `日期 + 平台` 主键去重
- 同一商品已存在则更新字段，不存在才新增，跳过无变化记录
- 同步结果统一封装为 `SyncResult`，记录新增/更新/跳过/失败数

### 4. 业务视图（提升查看体验）

**解决什么问题**：表格字段太多，业务用户查看时眼花。

**怎么做的**：
- 安装时自动创建 3 个业务视图（业务用户无需任何操作）：
  - **销售总览**：日期/平台/销售额/订单数/ACoS/异常标记/AI洞察
  - **预警看板**：ASIN/商品名称/SKU/平台/可售天数/预警等级/建议采购量/预估采购金额/审批状态
  - **选品决策**：商品名称/ASIN/品类/来源平台/价格区间/评分/评论数/市场容量/竞争强度/利润空间/推荐指数/状态
- 视图自动隐藏非关键字段，只显示业务关注的核心信息

### 5. 数据自动清理（每三天）

**解决什么问题**：表格数据越积越多，业务用户查看不便，且飞书单表上限 50000 条。

**怎么做的**：
- 每三天凌晨 2:00 自动执行数据清理任务（业务用户无需任何操作）
- 清理范围：选品池（按"分析时间"）/ 库存预警（按"更新时间"）/ 销售日报（按"日期"）
- 保留最近 3 天的数据，更早的数据自动批量删除
- **不清理**：采集配置表（企业长期配置）/ Listing 库表（保留优化历史）
- 保留天数可由 IT/运维人员在 `.env` 文件中通过 `DATA_RETENTION_DAYS` 配置（默认 3 天）

### 6. Webhook 机器人告警

**解决什么问题**：业务用户需要主动打开飞书表格才能发现库存问题，容易错过处理时机。

**怎么做的**：
- 库存预警等级变为"紧急"或"预警"时，自动发送交互卡片到飞书告警群
- 卡片包含：商品信息、可售天数、预警等级、处理建议、"查看库存详情"按钮
- 卡片颜色按严重程度区分：红色=紧急，橙色=预警
- 业务用户在群内即可看到告警，点击按钮跳转多维表格处理
- 仅"紧急"和"预警"等级告警，"关注"和"正常"不打扰（避免告警疲劳）

**消息类型支持**：
- 纯文本消息：简短通知
- 富文本消息：结构化多段落，支持加粗和链接
- 交互卡片消息：带按钮和分栏，按钮可跳转飞书表格

### 7. 定时调度

APScheduler + SQLite 持久化，支持开机自启的后台运行模式。

**任务清单**：

| 任务 | 触发时间 | 功能 |
|------|----------|------|
| 选品采集 | 工作日 9:00 | 多平台多品类增量同步采集 |
| 库存检查 | 每 30 分钟 | 更新预警等级 |
| 日报生成 | 每天 18:00 | AI 日报（第4周实现） |
| 数据清理 | 每 3 天 2:00 | 删除旧数据防止堆积 |
