### 核心交付物

**1. AI 调度层**（v0.5.0）
- ModelRouter：按任务复杂度（simple/standard/complex）自动选模型
- PromptManager：集中管理选品 Agent 的 3 个 Prompt 模板
- ToolRegistry：工具注册中心，Agent 按名称调用工具
- **v0.5.1 扩展**：支持国内大模型（DeepSeek/通义千问/智谱 GLM/Kimi）

**2. 选品 Agent**（v0.5.0 + v0.5.2 补漏）
- ReAct 模式，LangChain v1.0 `create_agent` + LangGraph
- 3 工具链路：`fetch_products` → `analyze_products` → `save_report`
- **v0.5.2 补漏**：
  - `save_report` 改用交互卡片（`build_ai_analysis_card`）推送，不再用纯文本
  - `create_agent` 加 `recursion_limit=10`，限制最多 5 轮工具调用，防止死循环

**3. 可观测性模块**（v0.5.0）
- LLMCallMonitor：LangChain Callback 自动记录每次 LLM 调用的耗时/Token/成本
- MetricsStore：SQLite 持久化调用日志，支持统计查询
- AlertChecker：近 1 小时失败率 >10% 自动飞书告警，30 分钟冷却防重复

**4. GUI 集成**
- [ai_agent_page.py](../../src/gui/pages/ai_agent_page.py)：AI Agent 操作页，选品类→运行→看日志
- [config_page.py](../../src/gui/pages/config_page.py)：新增 AI 模型配置分组（v0.5.1）

**5. 文档**
- README 新增第 11 章「AI Agent 使用说明」+ 第 12 章「国内大模型配置指南」
- ARCHITECTURE 新增「2.7 AI 调度层 + 选品 Agent」+「2.8 可观测性模块」

## 三、关键决策记录

| 决策 | 原因 | 影响 |
|------|------|------|
| 用 LangGraph 内置 messages 状态替代 MemoryStore | 避免过度设计，功能等价 | 减少一个模块，代码更简洁 |
| 推送方式从 send_text 改 send_card | 计划要求"交互卡片" | 飞书群收到美观的 AI 报告卡片 |
| 加 recursion_limit=10 | docstring 与代码不符 | 防止 Agent 死循环消耗 token |
| 国内大模型用 OpenAI 兼容接口 | 国内访问 OpenAI 需代理 | 一套代码兼容 4 家国内大模型 |
| 默认推荐 DeepSeek | 性价比最高 | 1 元 100 万 token，国内访问稳定 |
